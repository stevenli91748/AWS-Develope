# 三、我建议不要把所有东西都放 AWS

这里有一个很重要的区别：

### 开发代码

放：

```text
GitHub
   │
   ├── frontend/
   ├── backend/
   ├── ai/
   ├── tests/
   └── infrastructure/
```

### AWS

放：

```text
AWS
│
├── Amplify       → Frontend
├── ECS Fargate   → Backend
├── Bedrock       → LLM
├── RDS           → PostgreSQL
├── S3            → Documents
├── Cognito       → Login
├── ECR           → Docker images
├── CloudWatch    → Logs
└── Secrets       → API keys
```

这样你以后换 AWS、Azure、GCP 都不会被锁死。
